# ECON82300-Midterm
Interactive study guide for the ECON 82300 Applied Microeconometrics midterm (CUNY Graduate Center, Fall 2026).

Live site: https://markgsheppard.github.io/ECON82300-Midterm/

Includes 12 deck summaries with simulators, LaTeX math (MathJax), flashcards, per-deck checkpoints, a full quiz, 72 practice MCQs with a running grade, and optional topic-based examples. The "Ask Claude" tutor only works in the claude.ai version of the page.
